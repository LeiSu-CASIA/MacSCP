# 多协议剩余工作

完整目标继续适用，不能以 SFTP 测试通过替代所有协议完成。

## 已有基础

RemoteFileClient 承接所有远程文件功能，SFTPClient 为已实现的后端。客户端能力与底层进程分开；各传输入口共用 App 的工厂。0.1.11 回归为 59 组。

## FTP/FTPS 接入所需工作

1. 会话模型增加协议标识并保留旧 SFTP 配置、端点身份和恢复记录兼容；连接状态不再依赖 SSH master socket。实现独立的连接/取消/重连生命周期。
2. 连接表单增加 FTP/显式 FTPS/隐式 FTPS 设置，认证凭据只在所需生命周期中持有，不进入日志或站点导出。证书校验、超时及取消应有明确结果。
3. 实现目录浏览（MLSD 和 LIST 兼容）、编码与特殊名称、被动连接、属性、上传/下载、续传、目录创建/删除、重命名和时间戳能力。不支持的服务端能力应明确展示，不能假装支持 SFTP 的权限、链接或原子替换。
4. 决定并实现 FTP 覆盖语义：保留失败时的目标保护，能力不足时明确拒绝或经独立、具体的用户选择采用非原子策略，不得静默降低现有 SFTP 保护。
5. 使用自有 loopback FTP/FTPS 服务验证证书拒绝、取消、重试、二进制/空文件、中文与特殊名称、目录、失败保留及恢复；通过共用接口检查队列、同步、编辑和服务器中转。
6. 接入两栏界面、站点导入导出、恢复与协议能力启用条件，完成实际协议端到端验收后才标记支持。

## 0.1.12 进度

系统 libcurl 的 FTP/FTPS 基础传输与 MLSD/LIST 解析已经实现，并通过本机普通/显式/隐式 TLS 自建服务验证。此阶段不开放界面协议选择，后端 STOR 和重命名为原语，不代表已有安全最终发布或覆盖/续传策略。

下一阶段：实现完整 RemoteFileClient FTP 适配（元数据缺失处理、暂存发布、冲突、源变化、校验、续传/取消清理），再接入会话模型、认证生命周期及协议选择。不得因引擎实测通过就删除上方剩余需求。

## 0.1.13 进度

FTPClient 已接入 RemoteFileClient 的读取侧：目录、严格文件属性、SHA-256、普通下载和带前缀校验的 REST 下载续传；真实普通/显式/隐式 FTPS 共用队列、搜索、同步比较和目录统计已验证。未知大小/修改时间尝试 SIZE/MDTM；仍无法确认时拒绝使用伪造元数据进行下载或续传。

FTP 写入侧仍保持拒绝：尚需实现暂存上传/上传续传、源与前缀验证、取消清理、明确的非原子发布许可、冲突检查及最终发布策略，然后再开放协议登录与连接生命周期。读取侧完成不等于产品界面已支持 FTP。

## 0.1.15 写入侧进度

FTPClient 的上传、暂存 SHA-256 校验、APPE 续传、源与前缀校验、目录/空文件上传、保留时间与权限、远程流式复制已接入共用接口。写入默认仍拒绝，只有调用端明确设置 allowNonAtomic 才可执行；没有声明 FTP 具备原子替换能力。覆盖使用原目标版本校验、同目录回滚文件和发布后校验，恢复记录可识别发布阶段及确认丢失。一次性上传失败清理自己可确认的暂存；恢复上传保留暂存。无法确认原目标权限时，默认拒绝保留权限，不能把未知权限当作 000。

仍需完成：发布阶段恢复记录的同步持久化失败屏障；FTP 会话/端点身份、连接/取消/认证生命周期；界面协议选项和非原子许可；按服务端能力管理时间、权限、链接、终端等功能的启用；真实用户界面端到端验收。协议界面尚未开放，不能标记产品已支持 FTP/FTPS。

## 0.1.16 协议登录接入

会话模型现有可选协议和 FTP 设置，旧 SFTP JSON 与端点身份保持兼容；FTP、显式/隐式 FTPS 的端点身份与 SFTP 分离。新增统一登录表单、内存密码会话注册表、取消/关闭生命周期和独立会话客户端工厂；FTP 不再依赖 SSH socket 文件。实际 App 在三种自建 loopback 协议服务上完成隐藏窗口登录、浏览、队列上传、只读入口限制、独立会话关闭、错误密码、取消与过期回调拒绝、凭据不导出验证。

普通队列和中转的 FTP 发布关键阶段强制同步保存恢复记录，保存失败会阻止下一步写入；初始记录不可保存时不会 STOR，备份后保存失败会尝试恢复旧目标。此屏障针对保存错误及进程重启恢复，不宣称断电/磁盘故障下的事务保证。

仍需继续：FTP 站点 INI 字段映射与更多服务端能力协商/编码兼容、真实用户手势与更多服务端验收、SCP/WebDAV/S3 等原有完整范围。当前实现不得视为 WinSCP 全功能交付。


## 0.1.17 WinSCP FTP 迁移

已按官方协议枚举和原始设置定义实现 FTP、隐式及显式 FTPS 的 INI 映射，并接入列表偏好、连接超时及显式认证顺序的运行时配置。新增“FTP 高级设置…”；导入预览与设置差异显示这些值，密码/信任缓存不迁移，不兼容配置明确拒绝。

实际隐藏 App 已使用导入配置完成自建 FTPS 登录，强制 LIST 绕过拒绝 MLSD，服务端记录确认 AUTH SSL 优先；原生连接超时及仅 MLSD 拒绝回退已验证。主动 FTP、ACCT、客户端证书、自定义 TLS 范围及编码等仍待实现，不能把基本配置可迁移当作全部站点兼容。
