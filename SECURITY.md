# Security

This is preview software. Please test destructive or overwrite operations on disposable data first. Do not post credentials, SSH keys, tokens, host fingerprints or private server information in public issues.

For a potential vulnerability, use this repository's private vulnerability reporting feature if enabled, or contact the maintainer privately through their GitHub profile before publishing exploit details. No response-time guarantee is provided.

The project does not require disabling Gatekeeper, certificate validation or other system-wide protections. Do not accept instructions to upload your private keys or passwords for debugging.
